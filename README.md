# spring-gift-enhancement

---
## 1단계-엔티티 매핑
- 지금까지 작성한 JdbcTemplate 기반 코드를 JPA로 리팩터링
- 객체의 참조와 테이블의 외래 키를 매핑해서 객체에서는 참조를 사용하고 테이블에서는 외래 키를 사용할 수 있도록 한다.
- @DataJpaTest를 사용하여 학습 테스트를 해 본다.
---
## 2단계-페이지네이션
- 상품과 위시 리스트 보기에 페이지네이션을 구현
  - 페이지네이션은 원하는 정렬 방법, 페이지 크기 및 페이지에 따라 정보를 전달하는 방법
- 모든 게시글을 한 번에 표시하지 않고 여러 페이지로 나누어 표시
- 정렬 방법을 설정하여 보고 싶은 정보의 우선 순위를 정함
